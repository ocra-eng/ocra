| Status | What it means |
| --- | --- |
| Listed | An independently run event on the OCRA calendar. OCRA has not reviewed the competition. |
| OCRA Sanctioned | Reviewed against the standards for its level of competition. |
| OCRA Qualification Event | Results count towards qualification for a named international championship. |
| Irish National Championship | Irish titles are on the line, in the disciplines named on the listing. |

Only OCRA can grant the last three, and only in writing. A listing on the
calendar creates none of them.
