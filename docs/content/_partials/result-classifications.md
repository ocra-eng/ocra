Depending on the competition rules, a result may carry a classification instead
of a time:

DNS
: Did not start.

DNF
: Did not finish.

DNC
: Did not complete — finished the course, but without completing every obstacle
to the standard the rules require.

DSQ
: Disqualified.

Which of these applies, and what each one means for your placing, is set by the
rules of the specific competition.
